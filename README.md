# سدرة لخدمات التنظيف الشاملة | Sidra Clean

**الموقع الرسمي لشركة [سدرة لخدمات التنظيف الشاملة](https://sidraclean.com/)، شركة تنظيف في الرياض.** تقدّم الشركة تنظيف المنازل والقصور والمكاتب، وتنظيف واجهات المباني، وتنظيف خزانات المياه وتعقيمها، وتعمل في عدد من مدن المملكة.

الموقع مبنيّ على نظام إدارة محتوى خاص (Sidra CMS) طُوّر من الصفر بلغة PHP دون إطار عمل جاهز. فيه واجهة عربية من اليمين لليسار، ولوحة تحكم يدير منها فريق الشركة الخدمات والمدن والأحياء والمشاريع والمقالات.

🌐 **الموقع:** [sidraclean.com](https://sidraclean.com/)

## ماذا يحتوي المشروع؟ | What's inside

<div dir="rtl">

### للزائر (الواجهة العامة)
- **صفحات خدمات** مفصّلة لكل خدمة: تنظيف المنازل والقصور والمكاتب والواجهات، وأنواع خزانات المياه (خرسانية، فايبر، علوية، أرضية) وتعقيمها.
- **صفحات مواقع بمستويين:** صفحة لكل مدينة (الرياض، جدة، الدمام، مكة، المدينة، الخبر، أبها، تبوك)، وتحتها صفحات لأحياء الرياض.
- **مشاريع منفّذة** ومدونة بأدلة عملية، وآراء عملاء يستطيع الزائر إضافتها.
- **صفحات ثقة:** الضمانات، والصحة والسلامة، والتنظيف الصديق للبيئة، والتراخيص، وسياسة الشكاوى، ودليل ما قبل الخدمة.
- نموذج طلب عرض سعر.

### لفريق الشركة (لوحة التحكم)
- إدارة الصفحات والخدمات وتصنيفاتها، والمدن والأحياء، والمشاريع، والمقالات، والتقييمات، وآراء العملاء، والوسائط، والمستخدمين، والإعدادات.
- **صلاحيات حسب الدور (RBAC)** وتحقق بخطوتين (2FA) لحسابات الإدارة، مع سجل نشاطات.
- مولّد بيانات سيو، ومدير للروابط الداخلية، ولوحة لمتابعة التخزين المؤقت.

### البنية التقنية
- إطار PHP خاص مكتوب من الصفر: Router وContainer للحقن (Dependency Injection) وطبقات Middleware للمصادقة والصلاحيات و CSRF وتحديد معدل الطلبات.
- فصل واضح بين الطبقات: Controllers رفيعة، ثم Services، ثم Repositories هي وحدها التي تكتب SQL عبر Prepared Statements.
- تخزين مؤقت وطوابير مهام عبر Redis، ومهمة في الخلفية تولّد خرائط الموقع.

### السيو المحلي
- خرائط موقع XML مقسّمة (الصفحات، الخدمات، المقالات، المشاريع، المواقع)، وملفا `robots.txt` و`llms.txt`.
- بيانات منظمة (JSON-LD) للنشاط التجاري المحلي والأسئلة الشائعة.

</div>
